# ICRA 2026 Schedule Explorer

Static schedule explorer for ICRA 2026 technical papers and workshop timetable slots.

## Files

- `index.html`: self-contained GitHub Pages entry point.
- `icra2026_schedule_data.json`: generated schedule data for debugging and reuse.
- `build_icra2026_explorer.py`: builder script used to regenerate the page and data.

## Publish

Repository name:

```text
icra2026-schedule
```

Expected GitHub Pages URL:

```text
https://minwoo0611.github.io/icra2026-schedule/
```

GitHub Pages setting:

```text
Settings -> Pages -> Deploy from a branch -> main -> /root
```
